# Esitutkintalain (805/2011) kommentaari

Kommentaari suomalaiseen säädökseen: **Esitutkintalaki 22.7.2011/805**. Kommentaari kattaa **105 pykälää** (1–11 luku, mukaan lukien a-pykälät sekä voimaantulo- ja siirtymäsäännökset) **4 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö (ajantasaistettu **9.7.2026**, versio 20260698; viimeisin lähteessä mainittu muutossäädös 9.7.2026/698, joka tulee voimaan 1.6.2027 ja jonka muuttama 5 luvun 1 §:n 1 momentti esitetään lähteen mukaisesti tulevassa sanamuodossaan, aiempi sanamuoto lähteen huomautuksena).

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti ja sen metatiedot), ilman kaupallisia oikeudellisia tietokantoja. Säännösten sanamuoto on siirretty lähteestä koneellisesti ja sanatarkasti. Lähteen ajantasaistusmerkinnät, aiemmat sanamuodot ja muutossäädösten tiedot esitetään lähteen huomautuksina. **Oikeuskäytäntö ei sisälly tähän versioon** — se lisätään erillisessä vaiheessa.
